# 📚 Telco Customer Churn & LTV Engine - Data Dictionary

This data dictionary documents the baseline schema (21 raw features), engineered machine learning features, and Power BI enrichment attributes across the analytical pipeline.

---

## 1. Baseline Raw Dataset Schema (`data/WA_Fn-UseC_-Telco-Customer-Churn.csv`)

| Column Name | Data Type | Domain / Values | Description |
| :--- | :---: | :--- | :--- |
| `customerID` | String | e.g. `7590-VHVEG` | Unique alpha-numeric identifier for each customer |
| `gender` | Categorical | `Female`, `Male` | Customer gender |
| `SeniorCitizen` | Binary Int | `0` (No), `1` (Yes) | Whether the customer is a senior citizen (age >= 65) |
| `Partner` | Categorical | `Yes`, `No` | Whether the customer has a partner |
| `Dependents` | Categorical | `Yes`, `No` | Whether the customer has dependents (children, elders) |
| `tenure` | Integer | `0` to `72` | Number of months the customer has stayed with the company |
| `PhoneService` | Categorical | `Yes`, `No` | Whether the customer has home phone service |
| `MultipleLines` | Categorical | `Yes`, `No`, `No phone service` | Whether the customer has multiple phone lines |
| `InternetService` | Categorical | `DSL`, `Fiber optic`, `No` | Customer's internet service provider technology |
| `OnlineSecurity` | Categorical | `Yes`, `No`, `No internet service`| Whether the customer subscribes to online security |
| `OnlineBackup` | Categorical | `Yes`, `No`, `No internet service`| Whether the customer subscribes to online backup |
| `DeviceProtection`| Categorical | `Yes`, `No`, `No internet service`| Whether the customer subscribes to device protection plan |
| `TechSupport` | Categorical | `Yes`, `No`, `No internet service`| Whether the customer subscribes to premium tech support |
| `StreamingTV` | Categorical | `Yes`, `No`, `No internet service`| Whether the customer streams third-party TV programs |
| `StreamingMovies`| Categorical | `Yes`, `No`, `No internet service`| Whether the customer streams third-party movies |
| `Contract` | Categorical | `Month-to-month`, `One year`, `Two year` | Contract commitment terms |
| `PaperlessBilling`| Categorical | `Yes`, `No` | Whether the customer opts into electronic billing |
| `PaymentMethod` | Categorical | `Electronic check`, `Mailed check`, `Bank transfer (automatic)`, `Credit card (automatic)` | Customer billing payment method |
| `MonthlyCharges` | Numeric | `$18.25` to `$118.75` | Current monthly charge amount incurred by customer |
| `TotalCharges` | Numeric | `$0.00` to `$8684.80` | Total charges billed over lifetime (imputed 0.00 for tenure=0) |
| `Churn` | Categorical | `Yes`, `No` | Target variable: whether customer churned in last month |

## 2. Engineered Machine Learning Features (`src/train_models.py`)

| Feature Name | Type | Description & Formula |
| :--- | :---: | :--- |
| `tenure_cohort` | Categorical | Binned tenure: `0-12m`, `13-24m`, `25-36m`, `37-48m`, `49-60m`, `61-72m` |
| `total_addon_services` | Integer | Count (0–6) of active value-add services (`Security`, `Backup`, `DeviceProtection`, `TechSupport`, `StreamingTV`, `StreamingMovies`) |
| `security_bundle` | Binary Int | 1 if customer has both `OnlineSecurity == 'Yes'` AND `TechSupport == 'Yes'` |
| `streaming_bundle` | Binary Int | 1 if customer has both `StreamingTV == 'Yes'` AND `StreamingMovies == 'Yes'` |
| `charge_ratio` | Float | `TotalCharges / (tenure + 1)` — average effective monthly spend |
| `monthly_to_total_ratio` | Float | `MonthlyCharges / (TotalCharges + 1)` — recent price impact indicator |
| `has_family` | Binary Int | 1 if `Partner == 'Yes'` OR `Dependents == 'Yes'` |
| `is_month_to_month` | Binary Int | High-risk contract flag: 1 if `Contract == 'Month-to-month'` |
| `is_fiber_optic` | Binary Int | High-churn service flag: 1 if `InternetService == 'Fiber optic'` |
| `is_electronic_check` | Binary Int | High-friction billing flag: 1 if `PaymentMethod == 'Electronic check'` |
| `high_monthly_charges` | Binary Int | Price fatigue indicator: 1 if `MonthlyCharges >= 70.0` |

## 3. Power BI Enriched Output Attributes (`data/telco_churn_powerbi_dataset.csv`)

| Column Name | Type | Business Definition |
| :--- | :---: | :--- |
| `Churn_Probability` | Float | Model-estimated attrition probability (0.0000 to 1.0000) generated by XGBoost |
| `Predicted_Churn` | Categorical | Binary classification (`Yes` if probability >= 0.50 else `No`) |
| `Risk_Tier` | Categorical | Segment categorization: `High Risk` (>=0.60), `Medium Risk` (0.30–0.59), `Low Risk` (<0.30) |
| `Tenure_Cohort` | Categorical | Power BI display cohort (`0-12 Months` through `61-72 Months`) |
| `Expected_Future_Months` | Float | Estimated remaining lifetime months: `(1 - Churn_Probability) * 36` |
| `Expected_Future_Revenue`| Float | Projected future revenue: `MonthlyCharges * Expected_Future_Months` |
| `Customer_LTV` | Float | Lifetime value: `TotalCharges + (Expected_Future_Revenue * 0.80 contribution margin)` |
| `Annual_Revenue_At_Risk` | Float | Annual MRR exposed to churn: `MonthlyCharges * 12 * Churn_Probability` |
| `Recommended_Retention_Action`| Categorical | Rule-based, actionable prescription tailored to subscriber risk tier and root driver |
